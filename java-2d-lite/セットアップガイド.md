# FGCシミュレータ（軽量版）セットアップガイド

差動2輪ロボットのドライブ練習・3v3対戦シミュレータです。
このガイドだけで、何も入っていないWindows PCから起動・操作まで到達できます。

---

## 1. 動作環境

- **OS**: Windows 10 / 11（PowerShell使用。macOS/Linuxでも `./gradlew run` で動作します）
- **Java**: JDK 17 以上を推奨（下記手順でインストール）
- メモリ 4GB 以上・ネット接続（**初回ビルド時のみ**、ライブラリの自動ダウンロードに必要）

## 2. 環境構築（0から）

### 手順1: JDK のインストール

1. <https://adoptium.net/temurin/releases/> を開く
2. 「**Temurin 17 (LTS)**」の Windows x64 の `.msi` をダウンロード
3. インストーラを実行。途中の選択肢はすべてデフォルトのままでOK
   （「Set JAVA_HOME variable」を有効にしておくと確実です）
4. 確認: PowerShell を開いて `java -version` と打ち、`17.x.x` などが表示されれば成功

> 補足: 本プロジェクトは Gradle が適切な JDK を自動取得する設定（foojay-resolver）になっているため、
> 別バージョンのJavaが入っていても初回ビルド時に自動で解決されます。

### 手順2: プロジェクトの展開

1. `FGCシミュレータ_軽量版.zip` を右クリック →「すべて展開」
2. **日本語やスペースを含まない浅いパス**（例: `C:\fgc-sim\`）への展開を推奨

### 手順3: 起動

エクスプローラーで展開先フォルダを開き、アドレスバーに `powershell` と打って Enter → 開いたPowerShellで:

```powershell
.\run.ps1
```

- 初回はライブラリとJDKの自動ダウンロードが入るため **数分** かかります（2回目以降は数秒）
- シミュレータのウィンドウが開けば成功です
- ウィンドウを閉じると「キーを押すと再起動」モードになります（終了は Ctrl+C）

**`run.ps1` がスクリプト実行ポリシーでブロックされる場合**は、代わりにこちらでも起動できます:

```powershell
.\gradlew.bat run
```

## 3. 使い方

### 画面構成

- **上部タブ**: 「シングル走行（練習）」と「3v3 対戦」を切り替え
- **中央**: 7m×7mフィールド（ロボット・ボール・走行軌跡を表示）
- **右側パネル**: 機体パラメータ設定・タイマー・走行ステータス・リプレイ操作

### 操作方法

| 操作 | キーボード | ゲームパッド（Xbox系、接続で自動認識） |
|---|---|---|
| 前進 / 後退 | W / S（または ↑ / ↓） | 左スティック上下 |
| 左旋回 / 右旋回 | A / D（または ← / →） | 右スティック左右 |
| ボール回収（intake） | 画面の案内に従う | 〃 |
| 射出（shoot） / 排出（eject） | 〃 | 〃 |

- **最初にスティック（キー）を倒した瞬間にタイマーが自動スタート**します
- 2分30秒（150秒）経過で機体は強制停止し、走行ログが保存されます

### モード

- **シングル走行（練習）**: 1台でドライブ練習。右パネルでギア比・トレッド幅・摩擦係数・初期位置などを調整可能。練習モードをONにするとNPCも出現します
- **3v3 対戦**: 赤青3台ずつの対戦。自陣営の切替・対戦開始・リセットは右パネルから。NPCは自動で回収・射撃・妨害を行います

### ログとリプレイ

- 走行ごとに `logs/run_..._timeseries.csv`（50Hz時系列）と `logs/summary.csv`（サマリー1行）が自動保存されます
- 右パネルのリプレイ機能で過去のCSVを読み込むと、当時の設定込みで完全再現再生できます（一時停止・シーク・0.25x〜4x速度に対応）

## 4. フォルダ構成（配布物）

```
├─ run.ps1               ← 起動スクリプト（これを実行）
├─ gradlew.bat / gradle/ ← ビルドツール一式（インストール不要・自動取得）
├─ build.gradle / settings.gradle
├─ src/                  ← Javaソースコード（テスト含む）
├─ field_obstacles.json  ← フィールド障害物の定義（起動時に必須）
├─ config/  presets/     ← プレイヤー設定・機体プリセットの保存先
├─ README.md             ← 物理モデル・座標系などの技術詳細
└─ セットアップガイド.md  ← このファイル
```

## 5. トラブルシューティング

| 症状 | 対処 |
|---|---|
| `java` が見つからない | 手順1のJDKをインストール後、PowerShellを開き直す |
| `run.ps1` が実行できない（ポリシーエラー） | `.\gradlew.bat run` を使う |
| 初回ビルドが失敗する | ネット接続を確認（ライブラリの自動ダウンロードが必要）。社内プロキシ環境では管理者に相談 |
| ゲームパッドが反応しない | 起動前に接続しておく。未接続時は自動でキーボード操作になります |
| 起動時に `field_obstacles.json` 関連のエラー | 展開したフォルダ直下から起動しているか確認（`run.ps1` のある場所がカレントディレクトリになっている必要があります） |
| 動作確認（性能計測）をしたい | `.\gradlew.bat compileJava` 後、開発者向け: `practice.PerfBenchmark` をgson付きクラスパスで実行（詳細はREADME管理者へ） |

## 6. 技術情報（開発者向け）

- ビルド: `.\gradlew.bat compileJava` / テスト: `.\gradlew.bat test`（JUnit 5）
- 依存: gson 2.10.1（JSON）、jamepad 2.30.0.0（ゲームパッド）— Gradleが自動取得
- アーキテクチャや物理モデル（車軸ポーズ積分・スリップモデル・衝突解決）の詳細は `README.md` を参照
- コアロジック（`core` パッケージ）はUI非依存の純Javaで、FTC SDK / FTC Dashboard / MeepMeep への統合ポイントも `README.md` に記載
