# 差動2輪ロボット ドライブ練習シミュレータ (Java)

FTC (First Tech Challenge) の操縦練習用に設計された、差動2輪ロボットの上面図（トップダウン）シミュレータです。
物理モデル、運動学、走行ログ記録、リプレイ再生を完全に UI から分離したアーキテクチャ（純 Java コア）となっており、将来的に MeepMeep / FTC Dashboard / FTC SDK などのライブラリと容易に統合できます。

---

## 座標系と単位系

- **原点 (0,0)**: フィールドの左下
- **X軸**: 右方向が正 (+x)
- **Y軸**: 上方向が正 (+y)
- **向き (heading)**: $+x$ 軸方向（右向き）を $0$ とし、反時計回りを正とします（ラジアン）
- **基準座標（ボディ中心 G）**: 描画、走行軌跡、壁面衝突判定の基準となるのはロボット機体の幾何中心 G です。
- **単位系**: コア内部ではすべて国際単位系 (SI) に統一されています（メートル、ラジアン、秒、kg）。表示や設定入力の一部のみ度数法などに変換されます。

```
       +y (7m)
        |
        |      Robot (Body Center G, Wheel Center A)
        |       / \
        |      /   \  --> heading (0 = 右向き, 反時計回りが正)
        |
  (0,0)-+------------------ +x (7m)
```

## 主な機能

1. **車軸ポーズ積分とボディ中心幾何導出 (ピボット旋回)**:
   - 非ホロノミック拘束に従い、積分対象を**車軸ポーズ A (xA, yA, theta)** とし、ボディの中心 G を車軸 A から幾何オフセット `G = A - d * (cos theta, sin theta)` （$d>0$ は車軸がボディ中心より前方にある場合）で毎フレーム算出します。
   - これにより、その場旋回（並進指令 $0$）時に車軸 $A$ が前後並進しない正しい挙動が得られます。
2. **簡易スリップモデル (摩擦円) とゼロクランプ**:
   - 前後加減速と旋回による遠心力の合成加速度がタイヤと路面の静止摩擦限界 $\mu_{static} \cdot g$ を超えると横滑り（スリップ）が発生します。
   - スリップ中は接地動摩擦 $\mu_{kinetic} \cdot g$ に基づき横滑り速度 $v_{slide}$ が減速します。
   - 数値振動を防ぐため、ゼロ付近で $v_{slide}$ を完全に $0.0$ にクランプするゼロクロスクランプを導入しています。
3. **壁際境界でのクランプ（めり込み・跳ね返り防止）**:
   - 機体の四角形外形（0.5m x 0.5m、半径 0.25m）が $7\text{m} \times 7\text{m}$ の外縁境界に達した際、その境界軸（X軸またはY軸）方向の移動のみを位置クランプします。
   - 壁際接触中も、他方の軸方向へのスライド移動やその場旋回がスムーズに行えます。
4. **試合連動タイマー**:
   - 最初のスティック（キー）操作でタイマーが自動起動します。
   - 2分30秒（150秒）経過すると機体が強制停止し、操作を無効化します。
5. **時系列ログ & サマリー記録 (メタデータ埋め込み)**:
   - 走行中、固定 50Hz (20ms) で走行ログを自動サンプリングし、`logs/run_YYYYMMDD_HHMMSS_timeseries.csv` に保存します。
   - ログの最初の行に、その走行で使用したピボットオフセット $d$、トレッド幅 $w$、静/動摩擦係数、限界速度・限界加速度などの設定情報（`# Config:` メタデータ）が自動で記録されます。
   - 走行終了時（強制停止または手動停止）に走行データをまとめ、`logs/summary.csv` に1行追記します。
6. **リプレイ再生の完全再現**:
   - 過去に保存した時系列ログ CSV を読み込んで、その走行時の設定（$d$ やトレッド幅 $w$ など）をメタデータ行から復元して描画サイズ等を完全に再現再生できます。
   - 一時停止、シーク（スクラブ）、再生速度の変更（0.25x, 0.5x, 1.0x, 2.0x, 4.0x）に対応しています。

## パラメータ設定項目

コントロールパネル（画面右側）から以下の設定を動的に調整できます。
- **質量 (kg, 挙動未反映)**: デフォルト 13.5kg (調整範囲: 12.0 〜 15.0kg)
  - *※質量は今回の簡易物理モデル内ではデッドパラメータとなっています。将来的に a_max = F/m として駆動力と接続する拡張用のコメントをコード内に残しています。*
- **ギア比**: `1/12` (最高速 約 2.36 m/s), `1/15` (標準 約 1.88 m/s), `1/20` (低速 約 1.41 m/s) から選択。
- **トレッド幅 w (m)**: 0.30 〜 0.60m。左右の車輪幅。
- **ピボット d (m)**: -0.25 〜 0.25m。旋回ピボット（車軸中心）のボディ中心からのオフセット。
- **静止摩擦係数 (μS)** / **動摩擦係数 (μK)**: スリップ発生閾値とスリップ中の減速率。
- **初期位置・初期向き**: 開始時の初期配置 $(x, y, \theta)$ を設定可能。

## 操作方法

### ゲームパッド (推奨)
Xbox コントローラーなどのゲームパッドに対応しています（起動時に自動認識されます）。
- **左スティック Y軸**: 前進 / 後退 (並進指令)
- **右スティック X軸**: 左右旋回 (角速度指令)

### キーボード (フォールバック)
ゲームパッドが接続されていない場合は、キーボード操作に自動でフォールバックされます。キーボードのデジタル入力は、滑らかに反応するようにフィルタリング処理されます。
- **W / ↑ キー**: 前進
- **S / ↓ キー**: 後退
- **A / ← キー**: 左旋回（反時計回り）
- **D / → キー**: 右旋回（時計回り）

## FTCライブラリ統合時の設計（差し込みポイント）

本プロジェクトは、FTC Dashboard や MeepMeep, FTC SDK への統合を容易にするため、`core` パッケージを完全に分離しています。

- **物理エンジン・制御周期**:
  - `SimulationEngine` が 50Hz で `tick(dt)` を回す設計になっています。FTC SDK 内の TeleOp で動作させる場合は、`LinearOpMode` のループ内でループの delta time または固定 dt を `tick(dt)` に与えて呼び出すことで、物理・ログ・タイマーをそのまま流用できます。
- **描画アダプタの差し替え**:
  - 現在の Swing 描画 (`FieldPanel`) の代わりに、MeepMeep や FTC Dashboard (Telemetry / Field Overlay) に差し替えるには、`SimulationEngine.EngineListener` を実装し、`onStateUpdated(RobotState)` コールバックからロボットの位置 `(x, y)` と向き `heading` を取り出し、各ライブラリの描画命令（例: `fieldOverlay.strokeRect` または MeepMeep の `RoadRunner` パス描画）に橋渡しするだけで完了します。
- **入力ソースの差し替え**:
  - `InputSource` インターフェースを実装し、FTC SDK の `gamepad1.left_stick_y` と `gamepad1.right_stick_x` の値を返すアダプタ（例: `FTCGamepadAdapter`）を作ることで、本シミュレータの物理制御ロジックにそのまま接続できます。
