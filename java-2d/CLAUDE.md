# プロジェクト共通の作業ルール（Claudeへの指示）

## ツール呼び出しの書式を厳守する
ツール呼び出しは必ずハーネスの正規の関数呼び出し書式で行うこと。先頭に余計な語を付けたり、名前空間プレフィックスの無いタグを地の文に書いたりしない。

## 書式ミス（malformed）が起きたら自律的に修正して継続する
ツール呼び出しが「malformed / 解析不能」となった場合は、ユーザーに確認を求めて止まらず、ただちに書式を正しく直して同じ操作を再実行し、作業を継続すること。承認不要設定（bypassPermissions）が有効なので、確認を挟まず前に進める。同じ書式ミスを繰り返さないよう、直前の出力の何が誤っていたかを認識してから出し直す。
