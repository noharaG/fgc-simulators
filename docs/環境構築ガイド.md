# 環境構築ガイド — FGCシミュレーター レベルマックス

受け取った人がゼロから動かすための環境構築手順。ここだけ読めば起動まで到達できる。
詳細・経緯は [README_SETUP.md](../README_SETUP.md) / [HANDOFF.md](../HANDOFF.md) / [PLAN.md](../PLAN.md) を参照。

---

## 0. 何を用意するか（チェックリスト）

| 区分 | 必要なもの | 備考 |
|------|-----------|------|
| OS | Windows 10/11 | 本プロジェクトはWindows前提 |
| GPU | VR動作可能なGPU | 開発機は RTX 4070 Laptop（Ryzen 9 7945HX / RAM 32GB） |
| Unity | **Unity Hub** + **Unity 6 LTS エディタ** | バージョンは§1。モジュール `Windows Build Support (IL2CPP)` |
| VR | **Meta Quest**（Quest 2 等）+ **Quest Link** | PCVR表示用。無くてもデスクトップ画面で動作確認は可 |
| ゲームパッド | PS4互換パッド（開発機は REV-31-2983） | 操縦用。無くてもNPC観戦は可 |
| Python（任意） | Python 3.10 | **ML学習を将来使う時だけ**（§4）。通常起動には不要 |

> **重要:** 機械学習（ML-Agents）は現状 **無効化中**（Unity側のSentis→Inference Engine改称問題のため）。
> 本体シミュレーターはMLなしで完全動作する。MLスロットは自動でNPC代替される。詳細・再有効化手順は
> [HANDOFF.md](../HANDOFF.md) の「ML-Agents は現行Unityでは動かない」節を参照。

## 1. Unity の導入

1. **Unity Hub** をインストール（`winget install Unity.UnityHub` または公式サイト）。
2. Unity Hub を起動し、**無料 Personal ライセンス**でサインイン（※このログインだけはGUI必須）。
3. **Unity 6 LTS エディタ**をインストール。
   - 本プロジェクトの基準は **6000.0.x（Unity 6.0 LTS）**。`ProjectSettings/ProjectVersion.txt` は `6000.0.76f1`。
   - 追加モジュールで **`Windows Build Support (IL2CPP)`** にチェック。
   - エディタ版がProjectVersionと多少違っても、その版で開けばOK（`ProjectVersion.txt`は自動更新）。
   - CLIで入れる場合の手順・changesetは [README_SETUP.md](../README_SETUP.md) §1 / [HANDOFF.md](../HANDOFF.md) §5。

---

## 2. プロジェクトを開く

1. Unity Hub →「プロジェクトを追加」→ このフォルダを選択。
2. 初回オープンで `Packages/manifest.json` の依存が自動解決される（**数分かかる**）。主な依存:
   - Input System (1.19) / URP (17.4) / OpenXR (1.16.1) / XR Management (4.5.2) /
     XR Interaction Toolkit (3.4.1) / Newtonsoft.Json (3.2.2) / Test Framework
   - Input System 有効化の再起動ダイアログが出たら **Yes（Enable）**。
3. Meta XR SDK が要る場合は、起動後に Package Manager から追加（manifestには含めていない）。

---

## 3. 起動して動かす

1. メニュー **「FGC > Build Field Scene」** をクリック → フィールド一式・ロボ・500球・XR Origin等が生成。
2. **Play** → IMGUIの「FGC セットアップ」窓でモード/同盟/身長/スロットを設定 → **「試合開始」**。
3. **ゲームパッド**: 左スティックY=前後 / 右スティックX=旋回 / LT=回収 / RT=シュート / △=登攀（暫定）。
4. **VR表示**: Quest Link接続後、**Project Settings > XR Plug-in Management > OpenXR** を有効化
   （Meta Quest feature group にチェック）→ HMDに選手視点で表示。
5. 初回コンパイル時の既知の微修正項目は [README_SETUP.md](../README_SETUP.md) §4 を参照。

---

## 4. （任意）ML学習環境 — 将来 ML-Agents を再有効化する場合のみ

現状MLは無効なので**通常は不要**。再有効化する場合：

1. **Python 3.10** を用意（ML-Agentsはtorch/mlagentsの都合で3.10系。3.13は不可）。
   `winget install Python.Python.3.10`
2. PowerShellで **`./ml/setup_env.ps1`** を実行 → `ml/.venv310` にvenvを作り、torch（cu121）+ mlagentsを導入。
3. 学習は **`./ml/train.ps1`**、設定は `ml/fgc_ppo.yaml`。
4. Unity側の再有効化（manifest復帰・asmdef参照戻し・Scripting Define `FGC_MLAGENTS` 追加）は
   [HANDOFF.md](../HANDOFF.md) の「ML再有効化の手順（将来）」を参照。

---

## 5. つまずいたら

- パッケージ解決が終わらない/エラー → 一度Unityを閉じ、`Packages/packages-lock.json` を削除して再オープン（再生成される）。
- 画面がマゼンタ（ピンク）一色 → URPアセットが Project Settings > Graphics / Quality に割当たっているか確認。
- VRが表示されない → Quest Link疎通 → OpenXR有効化（§3-4）→ エディタ再起動。
- その他の既知の罠は [HANDOFF.md](../HANDOFF.md) の「ハマりどころ・教訓」節に集約。
